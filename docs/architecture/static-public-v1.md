# Static public site v1

## Purpose

Generate public Toen pages as one HTML file per URL. Keep current Next/OpenNext deployment unchanged while shadow output proves route, classroom, search, SEO, and asset parity.

Public origin remains `https://toen.stijnvh.workers.dev`. No paid domain, R2 delivery path, or runtime GitHub read is required.

## Build

Run:

```bash
pnpm build:static
```

Build sequence:

1. Synchronize content from an exact clean content SHA.
2. Generate release-qualified search and facets artifacts.
3. Stage content-addressed media and hashed search Worker.
4. Run Next build to compile shared Tailwind CSS and local font files.
5. Render shadow public output to `.generated/static-site`.
6. Verify manifest, route inventory, symbolic-link policy, sidecar exclusions, and file budget.

Generator consumes canonical parsed events and reuses `EventArticle`, `BeatPlayer`, `EventExplorer`, `HistoricalVisualFigure`, and archive components. Shared browser bundles hydrate homepage search and classroom controls. Article and archive pages ship no page-specific JavaScript.

## Output contract

For each event:

- `events/<slug>.html` serves `/events/<slug>`.
- `events/<slug>/play.html` serves `/events/<slug>/play`.

Cloudflare `html_handling = "drop-trailing-slash"` maps extensionless canonical URLs to these files. `not_found_handling = "404-page"` preserves real 404 responses.

Shared output includes:

- one compiled CSS file and referenced local WOFF2 files;
- split, content-hashed homepage and classroom JavaScript;
- one content-addressed WebP for each visual referenced by current events;
- release-qualified `search.json` and `facets.json`;
- hashed search Web Worker;
- homepage and crawlable period/topic archives;
- `sitemap.xml`, `robots.txt`, `_headers`, `favicon.svg`, and `404.html`.

Output rejects Markdown, RSC files, source maps, Next segment sidecars, symbolic links, unsupported filesystem entries, unsafe paths, and files outside explicit copy rules.

## Metadata

Article pages include:

- absolute canonical URL;
- title and description;
- Open Graph article metadata;
- `Article` and `LearningResource` JSON-LD;
- complete article body and source links in initial HTML.

Classroom pages include `noindex,follow` and canonicalize to article URL. Classroom URLs never enter sitemap. Homepage and archive pages remain crawlable.

Inline JSON escapes HTML-significant characters before insertion. Canonical event parsing and React rendering continue hostile-input isolation.

## Capacity

5,000-event benchmark result:

- 10,032 HTML files;
- 10,043 generated files before media;
- 15,043 projected files with one media file per event;
- 76,779,620 aggregate generated bytes before projected media;
- 4.66-second generation time;
- 228,540,416-byte peak RSS;
- zero Markdown, RSC, source-map, or segment sidecar files.

Report: `/tmp/toen-static-site-5000-final.json`.

Generator targets at most 10,500 HTML files. Complete public output targets 16,000 files and fails above 18,000, below Cloudflare Free 20,000-file limit.

## Validation

Current four-event exact-SHA shadow build contains 44 files and 22 HTML files. Repeated generation produced byte-identical tree hash `2b82c3d80559d4389d937a8aaf206e349b616c78ac1d39c58efb2d0ace8c9bde`.

Local Wrangler Static Assets checks proved:

- article and classroom canonical URLs return `200`;
- trailing-slash article URL redirects to canonical URL;
- unknown event returns `404` with generated 404 page;
- public homepage, event, and classroom BDD suite passes 61/61;
- Wrangler dry-run accepts assets-only configuration without bindings or deployment.

Wrangler logs 63 recursive directory entries for current tree. Asset manifest contains 44 actual files; directory entries are not uploaded assets.

## Deployment boundary

`wrangler.static.jsonc` targets separate `toen-static-canary` service. Configuration is shadow-only. Creating service, uploading version, publishing preview, changing Access, or replacing production remains approval-gated.

Keep current OpenNext public and admin routes until static canary, admin split, rollback drill, and operator cutover approval pass.
