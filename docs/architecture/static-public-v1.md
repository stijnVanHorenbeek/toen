# Static public site v1

## Purpose

Generate public Toen pages as one HTML file per URL. Production Static Assets serve routes, classroom flows, search, SEO metadata, and immutable media without OpenNext runtime rendering.

Public origin remains `https://toen.stijnvh.workers.dev`. No paid domain, R2 delivery path, or runtime GitHub read is required.

## Build

Run:

```bash
pnpm build:static
```

Build sequence:

1. Synchronize content from an exact clean content SHA.
2. Generate release-qualified search and facets artifacts.
3. Stage content-addressed media and hashed search Worker.
4. Run Next build to compile shared Tailwind CSS and local font files.
5. Build and package-check native admin API Worker.
6. Render public output to `.generated/static-site`.
7. Verify manifest, route inventory, symbolic-link policy, sidecar exclusions, and file budget.

Generator consumes canonical parsed events and reuses `EventArticle`, `BeatPlayer`, `EventExplorer`, `HistoricalVisualFigure`, and archive components. Shared browser bundles hydrate homepage search, classroom controls, and protected admin SPA. Article and archive pages ship no page-specific JavaScript.

## Output contract

For each event:

- `events/<slug>.html` serves `/events/<slug>`.
- `events/<slug>/play.html` serves `/events/<slug>/play`.

Cloudflare `html_handling = "drop-trailing-slash"` maps extensionless canonical URLs to these files. `not_found_handling = "404-page"` preserves real 404 responses.

Shared output includes:

- one compiled CSS file and referenced local WOFF2 files;
- split, content-hashed homepage, classroom, and admin JavaScript;
- one content-addressed WebP for each visual referenced by current events;
- release-qualified `search.json` and `facets.json`;
- hashed search Web Worker;
- homepage and crawlable period/topic archives;
- `sitemap.xml`, `robots.txt`, `_headers`, `favicon.svg`, and `404.html`.

Output rejects Markdown, RSC files, source maps, Next segment sidecars, symbolic links, unsupported filesystem entries, unsafe paths, and files outside explicit copy rules.

## Metadata

Article pages include:

- absolute canonical URL;
- title and description;
- Open Graph article metadata;
- `Article` and `LearningResource` JSON-LD;
- complete article body and source links in initial HTML.

Classroom pages include `noindex,follow` and canonicalize to article URL. Classroom URLs never enter sitemap. Homepage and archive pages remain crawlable.

Inline JSON escapes HTML-significant characters before insertion. Canonical event parsing and React rendering continue hostile-input isolation.

## Capacity

5,000-event benchmark result:

- 10,033 HTML files;
- 10,051 generated files before media;
- 15,051 projected files with one media file per event;
- 77,439,784 aggregate generated bytes before projected media;
- 4.41-second generation time;
- 231,276,544-byte peak RSS;
- zero Markdown, RSC, source-map, or segment sidecar files.

Report: `/tmp/toen-static-site-5000-admin-final.json`.

Generator targets at most 10,500 HTML files. Complete public output targets 16,000 files and fails above 18,000, below Cloudflare Free 20,000-file limit.
